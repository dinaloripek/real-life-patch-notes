One line, 126 characters: a software patch note for the shower replay — step under the water and the brain replays your most embarrassing moment from 2014 at full volume, uninvited, every single time. Written in the terse register of a real release note, version number and all:

> v2.7.0: Fixed a bug where the brain replayed your most embarrassing moment from 2014 at full volume every time the shower ran.

The program writes exactly that line to `/output/entry.txt` and refuses to write anything outside the gate (1–160 characters, one line).

## Run it

```sh
node main.ts
```
